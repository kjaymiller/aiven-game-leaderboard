To add an event: fill in the form, tick the games being played there, and save. Each game gets its own game link, leaderboard link, arcade-cabinet URL and QR codes in the table, ready to paste into slides or posters. Every (event, game) pair keeps its own leaderboard, so events can run on the same dates. Only scores from an event's games go on its boards. Times are UTC; leave them blank for always open. A game's links come from the URLs set in the Games tab. Set a CTA (button text and link) to send players somewhere after they claim a score at this event; leave it blank for the default Inkless link.
